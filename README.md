Tech Stack: Python, Flask, HTML/CSS, MySQL, Pandas
Developed a web-based system to manage earthquake relief
operations including victim records, shelters, and resource
distribution. Designed and implemented a relational database to
maintain real-time data on affected individuals, supplies, and
relief centers. Built admin and user interfaces using Flask to
enable efficient data entry, tracking, and monitoring during
disaster response. Emphasized scalability, data integrity, and
structured workflows to support large-scale emergency
management.
